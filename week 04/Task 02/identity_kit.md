# Visual Identity Kit
**Author: Saad Ali · Machine Learning Track**

This file outlines the design tokens, fonts, and colors for Saad's ML portfolio.

---

## 1. Design Tokens

### Typography Specimen
- **Primary Body Font:** `Geist Sans`
  - *Weights:* 300 (Light), 400 (Regular), 500 (Medium), 600 (Semibold)
  - *Purpose:* Clean reading experience, high scanability.
- **Headings & Monospace Font:** `Geist Mono`
  - *Weights:* 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)
  - *Purpose:* Brand headers, monogram symbol `[S]`, and performance metrics/code panels.

---

## 3. Aesthetic Guidelines

- **The Frame, Not the Painting:** The UI must stay minimal and professional, using clean borders and high-contrast text to showcase the machine learning logs, metrics, and SVG charts without distracting visual fluff.
- **Micro-Animations:** Use subtle transition states (0.2s duration) for theme toggling, button hover offsets, and key dashboard pulse indicators to make the interface feel alive and interactive.
