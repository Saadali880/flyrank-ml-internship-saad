Subdomain Mapping

DNS Configuration & CNAME Resolution Lifecycle

This walkthrough details the steps and technical explanation for pointing a custom FlyRank subdomain (saadali.flyrank.ai) to my personal portfolio hosted on Netlify (saadali.netlify.app).

Concept 1

What is a CNAME Record?

A CNAME (Canonical Name) record is a type of DNS record that acts as an alias or a "nickname" pointing one domain name to another domain name, rather than pointing directly to a numeric IP address.

📞 The Phonebook Analogy:

Think of an A record (Address record) like a phonebook entry mapping a name directly to a phone number:

Saad Ali → +1 (555) 019-9234

A CNAME record is like mapping an alias to a name that already has a phone number associated with it:

Developer Saad → Alias of "Saad Ali" (which resolves to the number)

Why use a CNAME? If the IP address of the hosting server changes, only the target domain (saadali.netlify.app) needs to update its A record. The alias subdomain (saadali.flyrank.ai) continues to resolve perfectly without any updates.

Concept 2

Subdomain Record Details

Once provisioned at the end of the internship track, the CNAME record is configured in the domain zone file with the following settings:

Host (Subdomain) Type Value (Destination) TTL
saadali.flyrank.ai CNAME saadali.netlify.app 3600 (1 Hour)

This record maps the custom FlyRank-branded subdomain directly to the production Netlify deployment server.

Concept 3

DNS Resolution Lifecycle (Step-by-Step)

Below is what occurs behind the scenes in the ~100ms interval between a user requesting saadali.flyrank.ai and the portfolio loading in the browser:

1. The Request (Browser)

You enter saadali.flyrank.ai in your browser. The browser queries your local network's DNS Resolver (ISP or public resolver like 8.8.8.8).

2. The Root Nameserver

The Resolver queries the Root Nameserver (.), which directs the Resolver to the .ai Top-Level Domain (TLD) Nameserver.

3. The TLD Nameserver

The Resolver queries the .ai TLD server, which returns the Authoritative Nameservers configured for the flyrank.ai domain.

4. The Authoritative Nameserver

The Resolver queries the flyrank.ai Authoritative Nameserver. It checks the zone records and returns: "saadali.flyrank.ai is a CNAME alias pointing to saadali.netlify.app."

5. The Redirection (Netlify DNS)

The Resolver then contacts Netlify's Authoritative Nameservers to find the IP address of saadali.netlify.app, which returns the active server IP (e.g., 104.198.14.32).

6. Connection established

The Resolver returns the target IP address to the browser. The browser opens a secure HTTPS connection to Netlify's server, which serves the webpage files immediately.
